# Instruções: ChatGPT para Antigravity

Este diretório armazena os prompts mestres, roteiros analíticos e especificações refinadas pelo **ChatGPT** em conjunto com o **Usuário**, antes de serem transmitidos para execução no **Antigravity**.

---

## Convenção de Nomenclatura

- Arquivos devem seguir o padrão: `GPT-XXXX.md` (ex: `GPT-0001.md`, `GPT-0002.md`).
- Devem conter:
  1. **Objetivo Claro da Rodada:** O que deve ser alcançado.
  2. **Agentes Primários e Secundários:** Quais especialistas devem atuar.
  3. **Fronteiras e Restrições:** O que NÃO deve ser alterado.
  4. **Critérios de Aceitação (DoD):** Como saber que a missão foi cumprida.
