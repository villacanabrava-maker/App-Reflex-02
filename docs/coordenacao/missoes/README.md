# Dossiês de Missões (docs/coordenacao/missoes/)

Este diretório arquiva dossiês e artefatos específicos gerados no ciclo de vida de missões do App Reflex 02.

Cada subpasta corresponde a uma missão (`MIS-0001/`, `MIS-0002/`, etc.) e pode conter:
- Análises de impacto preliminares.
- Logs de execução detalhados.
- Anotações intermediárias de investigação.
