## 3. Comparativo de Engenharia: Spec Candidata vs. Implementação Final

| Componente | Proposta da Spec Candidata | Implementação Final Homologada | Motivo da Mudança / Benefício |
| :--- | :--- | :--- | :--- |
| **Autoria** | `is_authorial: boolean default true` | `source_role papel_autoria default 'UNKNOWN'` | **Segurança Epistêmica:** Nenhum claim novo pode presumir autoria sem evidência. |
| **Dimensões** | Mistura de status epistêmico com estilo | **3 dimensões estanques:** `epistemic_status`, `claim_type`, `source_role` | **Rigor Categórico:** Estilo poético não é estado ontológico de verdade. |
| **Cross-Table Integrity**| `id_usuario` duplicado sem amarração | `FOREIGN KEY (claim_id, usuario_id) REFERENCES claims(id, usuario_id)` | **Isolamento Relacional:** Impede que a proveniência do usuário A aponte para claim do usuário B. |
| **Source Ref** | `id_obra UUID NOT NULL` órfão | `source_type` + `source_id` + `source_version` | **Polimorfismo:** Permite claims de obras, fragmentos, notas e reflexões. |
| **Span & Hashing** | Indefinido | UTF-16 code units + SHA-256 com normalização NFC | **Compatibilidade PT-BR:** Imunidade a quebras com acentos e aspas curvas. |
| **Event-Ready** | Ausente | `origin_event_id UUID NULL` | **Linhagem Causal:** Pronto para a Wave 2 (Event Ledger) sem migrações destrutivas. |
