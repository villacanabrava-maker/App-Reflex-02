# Workflow — Investigação de Bug

1. Capturar sintoma, URL e horário.
2. Resolver ambiente/deployment/branch/SHA.
3. Consultar logs de runtime.
4. Identificar rota/código.
5. Confirmar dados live relevantes.
6. Formular hipótese explícita.
7. Criar branch curta.
8. Corrigir minimamente.
9. Adicionar teste de regressão.
10. Rodar typecheck/lint/test/build.
11. Abrir PR, aguardar CI.
12. Merge + deploy.
13. Reproduzir no runtime novo.
14. Atualizar continuidade.
