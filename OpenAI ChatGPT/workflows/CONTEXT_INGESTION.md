# Workflow — Ingestão de Documento/Conversa

1. Ler o material integral quando ele for base da tarefa.
2. Separar:
   - pedido do usuário;
   - fatos sobre o projeto;
   - pesquisa externa;
   - propostas;
   - decisões.
3. Verificar fatos de projeto contra GitHub/Supabase/Vercel.
4. Registrar apenas síntese reutilizável em `OpenAI ChatGPT/`.
5. Linkar para o arquivo original quando ele existir no repo.
6. Não promover pesquisa a decisão sem autoridade humana.
7. Não guardar segredo nem chain-of-thought.
