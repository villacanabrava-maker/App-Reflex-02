3. Prefer current primary sources: official docs/changelogs, standards, peer-reviewed papers and original repositories.
4. Verify fast-moving vendor docs before substantive claims.
5. Classify source type and limitations.
6. Distinguish external evidence from current Reflex runtime evidence.
7. Compare options against provenance, authorial sovereignty, memory-inference separation, PostgreSQL sovereignty, security, cost, latency and operational complexity.
8. Import ideas before dependencies.
9. Return evidence, alternatives, trade-offs, unresolved questions and proposed experiments.
