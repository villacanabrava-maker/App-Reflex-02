# Roteador de Skills para ChatGPT/Codex

Antes de improvisar um workflow, verifique Skills disponíveis na sessão.

## Skills do projeto
- `$openai-reflex-bootstrap` — início de nova sessão.
- `$openai-reflex-runtime-debug` — erros de runtime/Vercel.
- `$openai-reflex-supabase-safe` — banco, RLS, Auth, Storage.
- `$openai-reflex-cognitive-integrity` — Cérebro/IA/provenance.
- `$openai-reflex-continuity` — handoff e persistência de contexto.

## Skills oficiais úteis quando disponíveis
- Skill Creator — criar/atualizar Skills.
- Supabase — qualquer trabalho Supabase.
- Next.js — App Router, Server Components/Actions.
- React best practices — revisão após mudanças TSX.
- Investigation Mode — debugging sistemático.
- Vercel deployments/CI-CD — deploy/rollback.
- Vercel observability — logs e runtime.
- Agent Browser / verification — teste visual/E2E.
- Vercel env-vars — configuração de ambientes.

## Regra
A Skill do projeto define **como o Reflex trabalha**; a Skill oficial do fornecedor define **como a plataforma funciona hoje**. Use ambas quando aplicável.
