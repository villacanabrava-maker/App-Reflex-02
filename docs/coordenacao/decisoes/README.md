# Decisões de Coordenação (docs/coordenacao/decisoes/)

Este diretório registra deliberações de governança, pactos operacionais e acordos firmados entre o Usuário, o ChatGPT e o Antigravity que afetam o protocolo de continuidade e o fluxo de trabalho.

As decisões técnicas e de arquitetura de código permanecem documentadas nos ADRs canônicos em `docs/adr/`.
