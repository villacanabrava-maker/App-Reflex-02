# Workflow — Mudança Supabase

1. Invocar Skill Supabase.
2. Ler changelog/docs atuais.
3. Consultar schema live.
4. Mapear RLS, grants, functions, triggers e dependências.
5. Testar SQL de forma controlada.
6. Criar migration limpa e versionada.
7. Rodar advisors.
8. Validar queries e isolamento.
9. Aplicar no ambiente autorizado.
10. Reconsultar schema/advisors.
11. CI + runtime correspondente.
