# Instruções locais — OpenAI ChatGPT

Estas regras valem para trabalhos dentro desta pasta.

1. Esta pasta é memória operacional versionada, não dump de conversa.
2. Atualize somente fatos verificados, decisões humanas explícitas e contexto reutilizável.
3. Não armazenar segredos, PII desnecessária, cookies ou chain-of-thought.
4. Preserve histórico: prefira acrescentar evento no ledger a apagar contexto útil.
5. Se um snapshot ficar velho, atualize a data e marque o que foi verificado live.
6. Mantenha arquivos curtos; mova detalhes para documentos específicos.
7. Ao alterar Skills, valide formato `SKILL.md`.
8. Não duplicar documentação canônica sem motivo; linkar para `docs/**` quando possível.
