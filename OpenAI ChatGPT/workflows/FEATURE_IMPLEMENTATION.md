# Workflow — Feature

1. Traduzir pedido em regra de produto.
2. Definir comportamento esperado e não esperado.
3. Mapear domínios tocados.
4. Definir contrato de dados e segurança.
5. Implementar na menor superfície possível.
6. Adicionar estados de UI e acessibilidade.
7. Adicionar testes.
8. Validar CI.
9. Validar runtime.
10. Registrar decisão se houver mudança de regra.
